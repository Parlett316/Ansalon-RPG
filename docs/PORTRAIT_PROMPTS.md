# Dialogue portrait generation prompts

Copy-paste-ready prompts for an AI image generator, one block per image.
28 prompts total (12 canon Heroes x 2 expressions, Astinus x 2
expressions, plus a reaction shot each for Otik and Tika, who already
have their normal portrait). Derived from the sourced research and full
write-ups in `docs/TOWN_ART_PROMPTS.md` -- that file has the citations
and reasoning; this one is just the finished prompts, self-contained so
each can be pasted on its own.

**Background note**: these use the generic/neutral-backdrop default
(option 1 of the three laid out in `docs/TOWN_ART_PROMPTS.md`'s
"Portrait backgrounds" section) -- no specific location baked in. That
was the cheapest option and the one requiring zero code changes, but it
was never confirmed with you. If you'd rather bake in a signature
location per character (option 2) or hold off until runtime compositing
(option 3) is built, don't generate from these yet -- say the word and
the backgrounds get rewritten first.

Each prompt already carries the shared style direction, so they work
independently. Generate a few variations per prompt and pick the one
that best fits, same as the location-plate advice -- these are art
direction, not exact wording to force verbatim. If anything comes out
reading too close to a specific published fantasy franchise's look,
regenerate.

**Save each result as**: the filename noted under its heading, dropped
into `assets/portraits/`. No code or data changes needed either way --
the game already looks for these exact paths.
