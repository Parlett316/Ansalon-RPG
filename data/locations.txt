# Ansalon world data -- milestone 1 slice.
#
# Grammar (documented in full in docs/MAP_NOTES.md):
#   LOCATION <id>            starts a block; <id> is the stable key used by CONNECT and in-game state
#   NAME <text>              display name
#   REGION <text>             region name (not used by game logic yet -- reserved for the future timeline engine)
#   TERRAIN <tag>             free-form terrain tag
#   GLYPH <char>              single ASCII character drawn on the schematic map
#   POS <row> <col>           stylized (NOT geographic) position on the schematic grid
#   DESC <text>               one-line description shown by 'look'
#   CONNECT <id> <days> "<text>"   a one-way road to another location; add the reverse
#                                  CONNECT in the other block to make it two-way
#   END                       closes the block
#
# Blank lines and lines starting with # are ignored anywhere.
#
# Locations below cover the Solace -> Tarsis corridor from the opening of
# Dragons of Autumn Twilight. Positions are a stylized schematic layout
# loosely following their relative real-map placement (north/south/east/west
# only, not distances) -- see docs/MAP_NOTES.md for what's canon vs invented.
