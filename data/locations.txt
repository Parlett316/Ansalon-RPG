# Ansalon world data -- Milestone 2 (walkable overworld).
#
# Grammar (full detail in docs/MAP_NOTES.md):
#   LOCATION <id>        starts a block; <id> is the stable key used in game state
#   NAME <text>           display name
#   REGION <text>          region name (not used by game logic yet -- reserved for the
#                          future timeline engine)
#   TERRAIN <tag>          free-form descriptive tag (informational; the walkable
#                          terrain under the location comes from data/overworld.grid)
#   GLYPH <char>           single ASCII character drawn on the overworld viewport
#   TOWN                    (optional, no argument) marks this as a civilian settlement --
#                          a knocked-out player respawns at the nearest TOWN location,
#                          full-healed, instead of always Solace -- see docs/COMBAT_NOTES.md
#   SIZE <MEDIUM|LARGE>     (optional) rough importance tier for the World Map overview
#                          screen ('o') only -- widens that screen's footprint for this
#                          location. Omitted means the default single-cell size; the
#                          real-time walking viewport is unaffected either way. See
#                          docs/MAP_NOTES.md's "World Map screen" for sourcing.
#   POS <x> <y>            tile coordinates on the SAME grid as data/overworld.grid
#                          (480 wide x 320 tall -- see docs/MAP_NOTES.md for how
#                          these were placed: most are pixel-measured off a legible
#                          label/icon on the reference image, per Milestone 85;
#                          Darken Wood and Ice Wall Castle have no direct label on
#                          that image either and stay placed by relative geography)
#   DESC <text>            one-line description shown by 'look'
#   END                    closes the block
#
# CONNECT/roads are gone as of Milestone 2 -- travel time now emerges from
# actually walking the terrain (see world::Terrain), not graph edges. Roads
# are instead baked into data/overworld.grid as '#' tiles by
# tools/generate_overworld.py, which reads the POS below to know what to
# connect (see ROAD_PAIRS in that script).
#
# Blank lines and lines starting with # are ignored anywhere.
