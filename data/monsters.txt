# data/monsters.txt -- hand-authored monster roster for random encounters.
# Grammar: docs/COMBAT_NOTES.md. Stats are sourced from real 2e rulebooks
# (Monster Manual (2nd ed).pdf, actually the 1993 Monstrous Manual
# compilation, and TSR 2021 DragonLance Adventures.pdf for all five
# Draconians and the Thanoi) -- visually confirmed against rendered page
# images, not invented, EXCEPT the Gnoll/Ghoul/Skeleton/Zombie entries
# added in Milestone 34: no page-image renderer was available that
# session, so those four were instead cross-checked between two
# independent text extractions of the same PDF pages (see
# docs/COMBAT_NOTES.md for the caveat and page citations). The Owlbear,
# Wight, and Troll (added in Milestone 100) are also visually confirmed
# against rendered page images (Monster Manual p.284/360/349). The Giant
# Spider's real Type F poison bite is modeled (POISON below); the Baaz's
# 20% magic resistance, the Kapak's real paralysis-poison bite, the
# Ghoul's real paralyzing touch, the Skeleton's/Zombie's real
# damage-type/spell immunities, the Bozak's spellcasting, the Sivak's
# shapeshifting, the Aurak's mind control/dimension door/breath weapon,
# the Thanoi's cold immunity, the Wight's level drain and silver/magic-only
# vulnerability, and the Troll's regeneration are all different mechanics
# not modeled the same way (see COMBAT_NOTES.md) and still not modeled;
# Baaz's, Kapak's, Bozak's, Sivak's, Aurak's, and Thanoi's XP values are
# also simplified, see below. This project models Krynn specifically -- no
# orcs, matching Dragonlance's distinct bestiary. The Black Bear and Worg
# (added in Milestone 107) are visually confirmed against rendered Monster
# Manual page images (p.17, p.362); the Ice Bear (also Milestone 107) is
# visually confirmed against a rendered Dragonlance Adventures page image
# (p.76, the "Creatures of Krynn" chapter, same source as the Draconians
# and Thanoi) -- its THAC0 isn't printed (same gap as every other
# DLA-sourced monster) and is derived from this project's established
# HD-to-THAC0 pattern, and its XP is a per-hp formula simplified to a flat
# value near the average roll, same treatment as the Draconians' XP.
#
# MONSTER <id>            starts a block
# NAME <text>              display name
# HP <count> <sides> <flat>       rolled once per encounter
# AC <n>
# THAC0 <n>
# DAMAGE <count> <sides> <flat>   per hit
# STEEL <count> <sides> <flat>    steel pieces awarded on victory
# XP <n>                   awarded on victory
# POISON                   optional; a hit also forces a saving throw vs.
#                          poison (see docs/COMBAT_NOTES.md) -- currently
#                          only the Giant Spider has this
# EXCLUDE_TERRAIN <codes>  optional; space-separated world::TerrainInfo codes
#                          (see src/world/Terrain.cpp) this monster never
#                          appears on -- a real, sourced Climate/Terrain
#                          restriction, not gameplay tuning. Only Gnoll has
#                          one (see docs/COMBAT_NOTES.md).
# TERRAIN_BIAS <codes>     optional; space-separated terrain codes this
#                          monster is more likely to appear on -- invented
#                          flavor weighting informed by (not transcribed
#                          from) the monster's real Habitat/Society text,
#                          same "tuned, not sourced" honesty as
#                          encounterChancePercent (see docs/COMBAT_NOTES.md).
# ONLY_TERRAIN <codes>     optional; space-separated terrain codes -- the
#                          inverse of EXCLUDE_TERRAIN, a hard restriction to
#                          ONLY these codes. Invented gameplay restriction,
#                          not a sourced Climate/Terrain field. Only Thanoi
#                          has one (glacier), see docs/COMBAT_NOTES.md.
# MIN_TOWN_DISTANCE <n>    optional; the monster is never eligible unless the
#                          encounter tile is at least <n> tiles (straight-
#                          line) from the nearest civilian town -- invented
#                          gameplay tuning to keep high-danger monsters away
#                          from starting towns, not sourced. See
#                          docs/COMBAT_NOTES.md.
# GROUP <min> <max>        optional; how many of this monster appear in one
#                          encounter (default, and every monster without this
#                          line: always exactly 1). Sourced from the real
#                          Monstrous Manual/Dragonlance Adventures "No.
#                          Appearing" field, then clamped to this project's
#                          own invented playability cap of 4 -- see
#                          docs/COMBAT_NOTES.md's "Monster encounter groups"
#                          section (Milestone 113). Deliberately only applied
#                          to the roster's low/mid-HD "line troop" tier that
#                          pass -- every MIN_TOWN_DISTANCE-gated monster (Ogre/
#                          Kapak/Bozak/Sivak/Aurak/Wight/Troll) stays solo
#                          despite real No. Appearing data supporting groups
#                          for them too, deliberately deferred again at
#                          Milestone 125 rather than shipping an untested
#                          difficulty spike without also re-tuning those
#                          gates. Milestone 125 additionally grouped Thanoi/
#                          Ice Bear/Giant Spider (real data supports it and
#                          none carry a MIN_TOWN_DISTANCE gate). Owlbear and
#                          Ettin stay solo permanently, not just deferred --
#                          their own real No. Appearing prints a solitary
#                          number for a wandering encounter, with a larger
#                          figure only for a lair (Owlbear) or a rare,
#                          explicitly-exceptional gathered band (Ettin). See
#                          COMBAT_NOTES.md for the full findings.
# DESC <text>              shown when the encounter starts
# END                      closes the block
#
# The Lizard Man, Giant Toad, and Ettin (added in Milestone 112) are
# visually confirmed against rendered Monster Manual page images (p.227,
# p.345, p.135). Before picking these, DLA's own "Common Creatures of
# Krynn" chapter (pp.74-78, the same chapter Thanoi/Ice Bear came from)
# was checked for anything else unused: Dreamshadow/Dreamwraith (only
# exist inside a mindspin spell's illusion, not wandering monsters), Fetch
# (only reachable through mirrors/reflections), Minotaur (Bloodsea, a
# civilized, organized race, not monster-roster material -- same reason
# Kender/Gnomes aren't monsters), Shadowpeople (Sanction-only, and
# Sanction itself is out of scope, see docs/TIMELINE_NOTES.md), and
# Spectral Minion (bound to one specific death-site, a location/quest
# fixture, not a roaming encounter) -- none hold up under this project's
# wandering-overworld-encounter model, so the DLA well stays dry beyond
# Ice Bear. Lizard Man's real three-attack claw/claw/bite is simplified to
# its single most damaging hit (the bite), same treatment as the Ghoul's
# own claw/claw/bite; its advanced/Lizard-King tribal variants (same page)
# are left out, same restraint as the Troll's un-modeled variants. Giant
# Toad's real single 2-8 attack (2d4) needed no simplification; its Fire/
# Ice/Poisonous Toad variants (same page) are left out for the same
# reason. Ettin's real two-attack (2d8 left arm/3d6 right arm) is
# simplified to its stronger right-arm hit, same treatment as the Owlbear's
# own beak-only simplification; its real ability to speak "orc, goblin,
# giant" dialects is left out of its DESC entirely, same "no orcs on
# Krynn" restraint already applied to this whole roster.
#
# The Harpy, Griffon, and Stirge (added in Milestone 142) are visually
# confirmed against rendered Monster Manual page images (p.184, p.178,
# p.332). None needs a new grammar keyword. The Harpy's real "Singing and
# charm" song (which charms nearby humans/demihumans into standing still
# while it kills them) and its 50%-chance bone-club weapon variant are
# left unmodeled -- no charm/status-effect system exists for anyone yet,
# same restraint as the Kapak's paralysis-poison bite. The Stirge's real
# attached "Blood drain" (1d4/round once its proboscis hits, until killed
# or 12 points are drained) is likewise unmodeled, same restraint as the
# Owlbear's hug -- its DAMAGE below is only the initial proboscis hit.
# Neither the Harpy's real "land or coast" nor the Stirge's real "forests
# or subterranean" Climate/Terrain maps cleanly onto this project's
# terrain codes (no coast or subterranean code exists, and ocean/shallow
# water are both non-walkable, so no monster can ever be purely coastal
# or aquatic in this engine): the Harpy's TERRAIN_BIAS below is an
# invented, informed-not-transcribed grassland+hills stand-in for its
# coastline/well-traveled-path flavor, while the Stirge's forest half is
# directly representable and gets a hard ONLY_TERRAIN. The Griffon's real
# "Hills or mountains" Climate/Terrain is narrow and fully representable,
# so it gets a hard ONLY_TERRAIN too, same treatment as the Thanoi/Ice
# Bear's own narrow, sourced restrictions. The Harpy and Griffon (both
# multi-attack, claw/claw/bite) are simplified to their single most
# damaging real die, same treatment as the Ghoul/Owlbear/Troll/Black
# Bear/Ice Bear/Lizard Man above. STEEL isn't a sourced field in this
# project; the Harpy and Griffon (both HD7) are given the same STEEL tier
# as the roster's nearest HD neighbor, the HD6 Sivak. The Stirge is
# Intelligence: Animal (1), so it carries STEEL 0 0 0 despite its real
# Treasure Type D, matching every other Animal-intelligence monster in
# this roster (Wolf, Worg, Black Bear, Ice Bear). The Harpy and Griffon
# are also both gated MIN_TOWN_DISTANCE 35, the same bracket as the HD6
# Sivak/Troll pair (one Hit Die up from them, but without the Aurak's
# spellcasting-driven further gate) -- and, matching the established
# policy that every MIN_TOWN_DISTANCE-gated monster stays solo despite
# real No. Appearing data supporting groups, neither carries a GROUP
# line. The Stirge, by contrast, is low-danger (XP175, matching the Black
# Bear/Worg tier) and carries GROUP 4 4 instead (real No. Appearing 3-30,
# a swarm-tier "Clusters" organization, clamped to this project's
# playability cap), same "always a full band of 4" treatment as the
# Goblin/Kobold/Lizard Man above.
