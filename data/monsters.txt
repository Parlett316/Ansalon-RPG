# data/monsters.txt -- hand-authored monster roster for random encounters.
# Grammar: docs/COMBAT_NOTES.md. Stats are sourced from real 2e rulebooks
# (Monster Manual (2nd ed).pdf, actually the 1993 Monstrous Manual
# compilation, and TSR 2021 DragonLance Adventures.pdf for all five
# Draconians and the Thanoi) -- visually confirmed against rendered page
# images, not invented, EXCEPT the Gnoll/Ghoul/Skeleton/Zombie entries
# added in Milestone 34: no page-image renderer was available that
# session, so those four were instead cross-checked between two
# independent text extractions of the same PDF pages (see
# docs/COMBAT_NOTES.md for the caveat and page citations). The Giant
# Spider's real Type F poison bite is modeled (POISON below); the Baaz's
# 20% magic resistance, the Kapak's real paralysis-poison bite, the
# Ghoul's real paralyzing touch, the Skeleton's/Zombie's real
# damage-type/spell immunities, the Bozak's spellcasting, the Sivak's
# shapeshifting, the Aurak's mind control/dimension door/breath weapon,
# and the Thanoi's cold immunity are all different mechanics not modeled
# the same way (see COMBAT_NOTES.md) and still not modeled; Baaz's,
# Kapak's, Bozak's, Sivak's, Aurak's, and Thanoi's XP values are also
# simplified, see below. This project models Krynn specifically -- no
# orcs, matching Dragonlance's distinct bestiary.
#
# MONSTER <id>            starts a block
# NAME <text>              display name
# HP <count> <sides> <flat>       rolled once per encounter
# AC <n>
# THAC0 <n>
# DAMAGE <count> <sides> <flat>   per hit
# STEEL <count> <sides> <flat>    steel pieces awarded on victory
# XP <n>                   awarded on victory
# POISON                   optional; a hit also forces a saving throw vs.
#                          poison (see docs/COMBAT_NOTES.md) -- currently
#                          only the Giant Spider has this
# EXCLUDE_TERRAIN <codes>  optional; space-separated world::TerrainInfo codes
#                          (see src/world/Terrain.cpp) this monster never
#                          appears on -- a real, sourced Climate/Terrain
#                          restriction, not gameplay tuning. Only Gnoll has
#                          one (see docs/COMBAT_NOTES.md).
# TERRAIN_BIAS <codes>     optional; space-separated terrain codes this
#                          monster is more likely to appear on -- invented
#                          flavor weighting informed by (not transcribed
#                          from) the monster's real Habitat/Society text,
#                          same "tuned, not sourced" honesty as
#                          encounterChancePercent (see docs/COMBAT_NOTES.md).
# ONLY_TERRAIN <codes>     optional; space-separated terrain codes -- the
#                          inverse of EXCLUDE_TERRAIN, a hard restriction to
#                          ONLY these codes. Invented gameplay restriction,
#                          not a sourced Climate/Terrain field. Only Thanoi
#                          has one (glacier), see docs/COMBAT_NOTES.md.
# MIN_TOWN_DISTANCE <n>    optional; the monster is never eligible unless the
#                          encounter tile is at least <n> tiles (straight-
#                          line) from the nearest civilian town -- invented
#                          gameplay tuning to keep high-danger monsters away
#                          from starting towns, not sourced. See
#                          docs/COMBAT_NOTES.md.
# DESC <text>              shown when the encounter starts
# END                      closes the block

MONSTER bozak
NAME Bozak Draconian
HP 4 8 0
AC 2
# Real HD is a plain 4 (Dragonlance Adventures p.74) -- THAC0 isn't
# printed (same gap as Baaz/Kapak above), derived as 17 from this
# project's own HD-to-THAC0 pattern (see docs/COMBAT_NOTES.md), the same
# bracket as Ogre's real printed HD 4+1 -> THAC0 17.
THAC0 17
# Real attack is two claws (1d4/1d4) or by weapon -- identical wording to
# the Baaz's own stat line, so simplified the same way: a single 1d8
# weapon hit, since this project doesn't model multiple attacks per round
# for anyone.
DAMAGE 1 8 0
STEEL 3 8 0
# Real formula is "175 + 4/hp" -- simplified to a flat value near the
# average roll (4d8 averages 18), same treatment as Baaz's/Kapak's XP.
XP 247
# Bozaks are real spellcasters (cast as a 4th-level magic-user: burning
# hands, enlarge, magic missile, shocking grasp, invisibility, levitate,
# stinking cloud, web) -- Milestone 99 models the signature one, Magic
# Missile, as a real in-combat special attack (see CASTS_MAGIC_MISSILE
# below and docs/COMBAT_NOTES.md); the other seven spells, +2 saves, and
# 20% magic resistance stay unmodeled, same restraint as Baaz's unmodeled
# magic resistance. Its bone-explosion death trait (1d6 dmg/10 ft) is also
# unmodeled, same treatment as the Kapak's acid-pool-on-death.
# 40% chance per round to cast Magic Missile (1d4+1 per missile, 2
# missiles at "4th-level caster") instead of its weapon attack -- no
# attack roll, no saving throw, same PHB math as the player's own
# magic_missile spell. Invented pacing (the book gives no frequency for
# monster spellcasting) -- see docs/COMBAT_NOTES.md.
CASTS_MAGIC_MISSILE 40
# An officer-tier draconian (real spellcasting, HD4) -- too dangerous for a
# starting town's doorstep. Invented gameplay tuning, user-requested, not
# sourced (Dragonlance Adventures gives draconians no Climate/Terrain field
# to hang a real restriction on -- see docs/COMBAT_NOTES.md).
MIN_TOWN_DISTANCE 25
DESC A crested draconian levels a clawed hand crackling with raw magic, sizing you up like a problem to be solved.
END

# they kill, and assume their killer's form when slain themselves (unless
# the killer is larger, in which case they burst into flame instead) --

# unmodeled (no persistent per-monster identity or NPC-disguise gameplay
# exists to hang it on, and no status-effect system exists for anyone
# yet); so do +2 saves/20% magic resistance. Milestone 99 models the
# death-burst as a real retaliatory hit (see BURSTS_INTO_FLAME below) --
# the book's "killed by something larger" condition is dropped since this
# project has no SIZE stat to check against, so it always fires.
# Real 2d4 damage, no saving throw (Dragonlance Adventures p.75) -- unlike
# Baaz's stone/Kapak's acid/Bozak's bone-explosion, which stay flavor-only
# victory messages, this is a genuine retaliatory hit against the player.

# HD6, deeper into elite-tier than the Bozak above -- kept farther from
# towns accordingly. Invented gameplay tuning, user-requested, not sourced.
MIN_TOWN_DISTANCE 35
DESC A heavily armored draconian unslings a pair of wicked blades, its long tail lashing behind it like a whip.
END

MONSTER aurak
NAME Aurak Draconian
HP 8 8 0
AC 0
# Real HD is a plain 8 (Dragonlance Adventures p.73) -- THAC0 isn't
# printed, derived as 13 from the same HD-to-THAC0 pattern, one bracket
# further down from the Sivak above (see docs/COMBAT_NOTES.md). This is
# the highest HD this project has extrapolated the pattern to.
THAC0 13
# Real attack is twin energy blasts (1d8+2 each) or a spell -- simplified
# to a single 1d8+2 hit, same single-attack simplification as every other
# multi-attack monster in this roster.
DAMAGE 1 8 2
STEEL 4 10 0
# Real formula is "1,800 + 10/hp" -- simplified to a flat value near the
# average roll (8d8 averages 36), same treatment as the Bozak's/Sivak's
# XP above.
XP 2160
# Auraks are the most mechanically loaded draconian in the book: limited
# dimension door, suggestion/mind control, change self, polymorph self,
# at-will invisibility, a noxious-cloud breath weapon, and real 1st- to
# 4th-level magic-user spellcasting, plus 30% magic resistance and saves
# at +4. Milestone 99 models the breath weapon as a real special attack
# (see BREATH_WEAPON below); dimension door, mind control, change
# self/polymorph self, invisibility, and the full spell list stay
# unmodeled -- none of them translate cleanly into this project's
# positionless, no-disguise-gameplay 1v1 combat loop, same restraint as
# every other draconian's unmodeled traits. Its real three-stage death
# (immolation, then a lightning-ball transformation, then an explosion)
# is likewise unmodeled, as are its 30% magic resistance and +4 saves.
# 30% chance per round to breathe a noxious cloud instead of its weapon
# attack: save vs. breath weapon for half of 20 damage, or full damage
# and blinded (a -4 this-fight to-hit penalty -- the book names the
# condition but not a number, so this is invented). The book's real
# "three times per day" has no way to track across stateless encounters
# with no monster-instance persistence, so it's compressed to "available
# this whole fight," gated only by this per-round roll -- see
# docs/COMBAT_NOTES.md.
BREATH_WEAPON 30
# HD8, the most powerful thing in the roster -- kept the farthest from
# towns of any monster. Invented gameplay tuning, user-requested, not
# sourced.
MIN_TOWN_DISTANCE 45
DESC A tall, wingless draconian regards you with unsettling stillness, a voice that isn't yours already forming inside your skull.
END

# Skeleton's/Zombie's immunities above.
